## Routing rules (apply to ALL nav files in this folder)

### NEVER use left/right -- anchor to features

Left and right are perspective-dependent.

**The rule:**
- The **zone entrance** (loading point, first autosave checkpoint, first chamber) is the canonical reference. State it explicitly when giving directions.
- Describe forks by what they *contain* or *lead to*, not by left/right. Examples:
  - "From the entrance chamber, the path with the **dead-end loot stash** is worth sweeping first."
  - "The corridor with the **Aeldari inscription panel** is the main path; the other leads to a dead end."
  - "From the entrance: the **lower path** / **upper path** / **path through the blast door**."
- Cardinal directions acceptable when the in-game map shows them. Otherwise prefer feature anchors.
- Exception: z-quetza (Quetza Temer forest) is procedurally variable -- no directional guide matches across playthroughs. Use only feature-anchored prompts from `localization.md`.
- If a fork has no distinctive feature, ask the player to describe what they see.

### Save / checkpoint behavior

Rogue Trader uses a **manual save** system. No discrete save stations. Autosaves fire at zone entry, pre-boss, pre-major-choice dialogue, and companion recruitment. Community-reported as inconsistent; **recommended: manual save after every warp jump and every zone entry.** When entering a zone, remind the player to save manually before any irreversible action (specific dialogue, leaving a zone).

### Hint format on zone entry

When the player arrives at a zone and asks for help, **before any puzzle solutions**, give them **2-3 short navigation / anti-backtrack tips** (collectible/chest order, shortcut that skips loot, non-obvious correct exit). 3 tips max. Route hints only -- no puzzle solutions.

## Localization toolkit

This is a **hybrid** localization-mechanism game: star-system map for inter-system orientation; landmark-based navigation for dungeon and surface zones. See [`localization.md`](localization.md) for per-zone landmark references and player prompts.
