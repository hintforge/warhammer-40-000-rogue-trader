## Entry

Shuttle from Mortus Acies system (after 2-ship Drukhari void combat).

## Entry tips

1. The **SW side bag** near the landing has Shield-Bearer's Boots -- loot it before engaging Tazarra.
2. Save before the **Tazarra/Drukhari trap encounter** (south path); the gladiator-side selection check is important for downstream content.
3. The **NE chest** (Awareness + Tech-Use checks) holds Scorpion Sting + Melta Charge -- worth attempting before exiting.

## Sequential gates

1. **Loot side bag (SW)** -- Shield-Bearer's Boots. Near landing pad, before main encounter area.
   - `point_of_no_return:` none
2. **East fork** -- Approach toward main zone.
   - `point_of_no_return:` none
3. **Save before south path** -- Tazarra trap upcoming.
   - `point_of_no_return:` none (reminder point)
4. **Tazarra/Drukhari trap encounter** -- Ambush engagement.
   - `point_of_no_return:` none
5. **Gladiator-side selection** -- Persuasion -15 check OR Dogmatic option to recruit gladiators for main fight.
   - `point_of_no_return:` none
6. **Main fight** -- Arena combat with or without gladiator allies.
   - `point_of_no_return:` none
7. **NE chest** -- Awareness + Tech-Use checks; reward: Scorpion Sting + Melta Charge.
   - `point_of_no_return:` none (accessible while still in zone)
