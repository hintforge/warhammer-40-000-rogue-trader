## Entry

Shuttle from Telikos Epsilon system (Ch.2); webway emergence from z-webway (Ch.4 start -- z-janus-temple vignette leads here).

## Entry tips

1. **Do NOT attack the Aeldari during the first two dialogue replies** at the Webway Gateway (Aeldari ruins section) -- Yrliet is permanently removed if you do (Fextralife/gamerguides).
2. At the **jungle ravine fork**, the path toward the optional rebel camp (right fork) has a loot crate + Orthlak Mark IV chest. Sweep it before taking the main left path.
3. Manual save before the **Muaran/Webway Gateway confrontation** -- major choice (alliance/kill) with permanent consequences.

## Sequential gates

1. **Welcoming ceremony at Estate** -- Introductory NPC scene with Governor Vyatt.
   - `point_of_no_return:` none
2. **Rebel attack (two waves)** -- Combat; Estate defense.
   - `point_of_no_return:` none
3. **Search Operation (exploration)** -- Open exploration phase; find clues around estate/grounds.
   - `point_of_no_return:` none
4. **Jungle ravine -- fallen-tree fork** -- Right path = optional rebel camp (3 Lacerax + Alpha Lacerax, loot crate, Orthlak Mark IV). Left path = main route. Can clear right first then take left.
   - `point_of_no_return:` none (sweep both; only fork in the zone)
5. **Janusian Lacerax ambush** -- 2 Lacerax + Alpha Lacerax on main path.
   - `point_of_no_return:` none
6. **Trap bridge** -- Navigate bridge (combat/trap encounter).
   - `point_of_no_return:` none
7. **Ambushed rebel pickets** -- Combat encounter before Aeldari ruins.
   - `point_of_no_return:` none
8. **Bridge to Aeldari ruins** -- Approach to Webway Gateway.
   - `point_of_no_return:` none
9. **Muaran/Webway Gateway confrontation** -- Major choice: alliance with Aeldari / kill. **Do NOT attack during first two replies -- Yrliet removed permanently if you do.**
   - `point_of_no_return:` permanent (conviction and Yrliet consequences)

## Common confusions

## Soft-lock warnings
