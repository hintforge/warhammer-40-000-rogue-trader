## Entry

From z-arena via E09 (one-way post-final-arena).

## Entry tips

1. **Yrliet must be in the active party** for the elevator in this zone -- Owlcat-confirmed bug: without her in the active team, the elevator is blocked (roguetrader.owlcat.games/news/en/33). Keep Yrliet in party for the entire Spire arc.
2. **Northeast Awareness hidden chest** (Blitz Boots + Xenohide Gloves) is easy to miss -- check NE corner on the main hall floor before ascending.
3. **Tervantias's stifler force field** choice (Iconoclast leaves intact / Dogmatic or Heretical destroy it) adds +10 Veil Degradation permanently to all remaining Commorragh fights if destroyed. Save before it.

## Sequential gates

1. **Landing platform** -- Marazhai/Yrliet quest triggers fire (Path of the Drukhari / The Path We Lost).
   - `point_of_no_return:` none
2. **Maze level entry** -- Toxin-projectile turrets; disable via Lore (Xenos) consoles.
   - `lock:` Lore (Xenos) ability -- reduces difficulty significantly
   - `point_of_no_return:` none
3. **East path -- two large vats** -- Top vat: freeable entity (lore content). Regicide board with Yrliet. Imprisoned Farseer's Soul (give to Eklendyl later).
   - `point_of_no_return:` none
4. **Eastern chamber -- Eklendyl's hanging cage** -- Bloodthirsty Experiments + Disciples of Pain fight; top + bottom consoles lower cage to free Eklendyl.
   - `point_of_no_return:` none
5. **Eastern locker** -- Webway Resonance Device (needed if Marazhai is not opening the final gate).
   - `lock:` item (Webway Resonance Device) OR Marazhai active companion -- see architecture.md locks-and-keys
   - `point_of_no_return:` none
6. **Center console** -- Extends stairs northward.
   - `point_of_no_return:` none
7. **West detour -- torture chamber** -- Marazhai receives 2 Xenoplasm Grenades here if brought.
   - `point_of_no_return:` none
8. **Elevator up** -- Medicae check en route.
   - `point_of_no_return:` none (REQUIRED: Yrliet must be in active party -- see soft-lock warning)
9. **Main hall bridges** -- Traps and ambushes.
   - `point_of_no_return:` none
10. **Tervantias's stifler force field** -- Major conviction choice: Iconoclast leaves intact. Dogmatic/Heretical destroy it (adds +10 Veil Degradation permanently to remaining Commorragh fights).
    - `point_of_no_return:` permanent (Veil Degradation is permanent if destroyed)
    _source: P2 research cascade 2026-05-23 · capture: web_fetch · confidence: high · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: story_
11. **Northeast Awareness hidden chest** -- Blitz Boots + Xenohide Gloves. NE corner main hall; easy to miss.
    - `point_of_no_return:` none (available before ascending)
12. **North elevator to top**
    - `point_of_no_return:` none
13. **Top floor -- Yremeryss boss** -- 4 Incubus + 4 Grotesque. Heals to full at 50% HP, gets a free turn + 2 turrets. See corpus npcs/ for strategy (enemy-tier 1 content).
    _source: P2 research cascade 2026-05-23 · capture: web_fetch · confidence: high · enemy-tier: 1 · puzzle-tier: 0 · category: mainline · spoiler: progression_
    - `point_of_no_return:` none
14. **Webway Portal** -- Marazhai harvests Yremeryss soul; 4 Mandrakes arrive for Marazhai if he opened it. E10 fires: one-way to z-janus (z-janus-temple emergence).
    - `point_of_no_return:` permanent (E10 -- end of Ch.3, one-way to Ch.4)

## Optional branches

- **East path vats** -- Top vat lore content. Regicide board (Yrliet interaction; lore/optional).
- **West detour (Marazhai grenades)** -- Only relevant if Marazhai is in party.

## Common confusions

- "Elevator is blocked" -- Yrliet must be in the active party (Owlcat patch notes roguetrader.owlcat.games/news/en/33). If stuck at elevator, check that Yrliet is in the active team.
- "Stifler field: I destroyed it and now Veil is constantly high" -- The +10 Veil Degradation from destroying the field is permanent for remaining fights. This is intended.

## Soft-lock warnings

- **Yrliet elevator bug (Owlcat-confirmed)** -- "One of the options in The Path of the Lost quest could allow the player to continue the quest without Yrliet in the party, which was not intended and blocked the elevator in the Reaving Tempest Spire. Players who encountered this problem need to go back and pick up Yrliet for the quest to continue." (roguetrader.owlcat.games/news/en/33)

> **Cross-system dependency** -- see `dependencies.md` SEQ-013: same bug documented in `crew/yrliet-lanaevyss.md` Recruitment gate 2.

## Exit

E10 -> z-janus (via z-janus-temple emergence vignette). One-way, permanent (Ch.3 end).
