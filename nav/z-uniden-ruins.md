## Entry

Approach exploration-point nodes on the galactic chart within Cinerus Maleficum (Litoribum Maledicta, Lapidus Mortus, Last Chance of Cyrene). Lore (Warp) +20 check for some nodes.

## Entry tips

1. This is a **cluster of small exploration nodes**, not a single contiguous dungeon. Each node is a brief scan -> land -> 1-2 combats -> loot -> re-board sequence.
2. **Stash of the Children of Asuryan** (Yrliet's Aeldari in Distress completion) is at one of the cluster nodes -- required for that quest outcome.
3. Access closes at Ch.5 PoNR -- visit before entering Ch.5.

## Sequential gates

(Per node -- typical pattern)

1. **Scan node** -- System map action; Lore (Warp) check for some.
   - `point_of_no_return:` none
2. **Land** -- Shuttle to surface.
   - `point_of_no_return:` none
3. **1-2 combat encounters** -- Variable per node.
   - `point_of_no_return:` none
4. **Loot** -- Node reward.
   - `point_of_no_return:` none
5. **Re-board** -- Return to system map.
   - `point_of_no_return:` none

Notable site: **Stash of the Children of Asuryan** -- Yrliet's Aeldari in Distress quest completion node. Required for Yrliet companion quest.

## Optional branches

## Common confusions

- Players expect a single dungeon; the cluster is several small nodes spread across the system map.
