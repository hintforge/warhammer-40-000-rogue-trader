## Entry

From `z-prologue-flagship` via edge E01 (one-way, story-gate). Subsequently: shuttle return from any ground zone, or section-map from z-ship-upper/lower/cargo/quarters.

## Entry tips

1. The **Koronus Expanse Map console** (north-center of bridge) is the only inter-system fast-travel node. All warp jumps start here.
2. **Vigdis** (foot of stairs) provides chapter-keyed rumors -- check her after each warp jump for new leads.
3. If the **Eufrates II war-council bridge cutscene** fails to trigger in Ch.4, verify files via Steam (known bug: Janris dialogue re-fires instead -- see common confusions).

## Sequential gates

1. **Koronus Expanse Map console** -- Sole inter-system fast-travel node. All warp jumps originate here.
   - `point_of_no_return:` none (access preserved throughout game)
2. **Captain's chair** -- Post-effects and ultimate abilities for void combat. Available after Prologue.
   - `point_of_no_return:` none
3. **Vox-Master Vigdis** -- Rumors and voidship developments. Chapter-keyed; check after each jump.
   - `point_of_no_return:` none
4. **Janris Danrok** -- Trade, colony management, fast-track merchants (Ch.2+). Dialogue can re-trigger buggily in Ch.4 (see below).
   - `point_of_no_return:` none
5. **Bridge cogitator** (Classified Information) -- Theodora's data cache available after Pasqal blood test. Required for "How Did It All End?" achievement chain.
   - `point_of_no_return:` missable-trigger (Ch.2 window; deferred after Dargonus inauguration)
6. **North exit to Voidship Shrine** -- FURIA plate puzzle in z-ship-upper. Accessible Ch.1+.
   - `point_of_no_return:` none
7. **Section-map exits** -- Reach z-ship-upper / z-ship-lower / z-ship-cargo / z-ship-quarters at any time.
   - `point_of_no_return:` none
