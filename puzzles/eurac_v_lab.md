## Hint Ladder

**Lvl 1 (nudge):** This is a component-combination puzzle with two valid output paths. Read the labels on each flask -- the Tissue Flask and Catalyst Flask are the key first step.

**Lvl 2 (more):** Connect the Tissue Flask to the Catalyst Flask first, then attach the Reagent Flask to the output port. The Transducer and Data-Crypt Connector go to the secondary ports. Two final combinations yield different rewards -- decide before committing.

**Lvl 3 (full solution):**

**Branch A -- Adaptive Antidote x6 (healing):**
1. Insert Tissue Flask into Slot 1.
2. Connect Catalyst Flask to Slot 2.
3. Add Reagent Flask to Slot 3.
4. Attach Transducer to secondary port A.
5. Insert Data-Crypt Connector to secondary port B.
6. Confirm synthesis -- select "Adaptive Antidote" branch.

**Branch B -- Elixir of Warp Neutrality x6 (Warp resistance):**
Steps 1-5 identical.
6. Confirm synthesis -- select "Elixir of Warp Neutrality" branch.

Both rewards are one-time. Choose based on party build: Adaptive Antidote for Nurgle/poison-heavy zones; Elixir for high-psyker or Warp-event-heavy play.

## Reward

- **Branch A:** Shimmering Emulsion x1 -- permanently grants +1 Psy Rating, +30% chance to trigger Perils of the Warp. **Psyker-only as of Patch 1.5** (Oct 23 2025); non-psykers cannot use it. (Older guides call this "Adaptive Antidote" with a per-battle effect -- stale since pre-1.5 patch)
- **Branch B:** Viscous Solution x1 -- permanently grants +1 Deflection, -10 Agility. (Older guides call this "Elixir of Warp Neutrality" with a per-battle effect -- stale since pre-1.5 patch)

Only one branch available per run; selecting the reward locks out the other.

## Notes

- Bug-prone puzzle (Fextralife community notes). **Save before starting component placement.**
- If component slots fail to respond, reload and try again before the cogitator step.
- The Data-Crypt Connector and Transducer position can be swapped without changing output in most patch versions; confirmed consistent in Build 21262645.
