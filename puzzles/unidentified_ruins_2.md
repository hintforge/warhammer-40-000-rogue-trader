## Hint Ladder

**Lvl 1 (nudge):** This is a directional sequence puzzle. The ruins contain markings in compass directions -- the correct order matters.

**Lvl 2 (more):** You need to activate the sequence in a specific compass-direction order. The pattern starts from the East.

**Lvl 3 (full solution):** Activate in the order: **E -> NW -> N -> S -> SW -> E** (East, Northwest, North, South, Southwest, East).
[First documented by Reddit user Desthion]
