## Difficulty (Game tab or Options > Gameplay -- unverified tab name)

Five tiers. Difficulty can be changed mid-run except Grim Darkness.

| Tier | Notes |
|---|---|
| Story | Reduced combat challenge |
| Normal | Standard experience; ~140h first run |
| Core | Harder; increased stat modifiers on enemies |
| Hard | Harder still |
| Daring | Hardest non-ironman; required for all Votary-ending achievements and several combat achievements |
| Grim Darkness | Ironman; single save slot; triggers "There Is Only War..." (0.7% global); cannot change difficulty once started |

Many achievements are **Daring+ locked:** Don't Touch This, Aviation Saviour, Friendly Warp-Fire, Valuable Player, Collateral Damage, Release the Hound!, A Little Too Crowded, Overcome and Overpower, and all four Votary endings (Deepest Conviction, Merciful Soul, The Emperor's Servant, Chaos Incarnate).

_source: P1 research cascade 2026-05-22 · capture: web_fetch · confidence: high · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_

**Recommendation:** start on Daring+ if going for any achievement run. Difficulty can be lowered later if needed, but starting on Story/Normal and switching up is blocked after Grim Darkness selection.

## Multiplayer / Co-op

Up to 6 players co-op added free post-launch. Most useful in Ch4 for conviction-branch decision flexibility. Co-op does not bypass achievement requirements (Daring+ achievements still require Daring difficulty in co-op sessions).
